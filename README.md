# Iris Online Database 2.0.6

Iris Online Database — неофициальная локальная база предметов, монстров, титулов, рецептов, сундуков, комплектов и источников добычи Iris Online.

Версия 2.0 — настольное приложение для Windows. `IrisOnlineDatabase.exe` открывает собственное окно на Wails 2.14.0 и Microsoft WebView2: без адресной строки, внешней вкладки браузера и TCP-порта для интерфейса. HTML/CSS/JavaScript и игровые данные встроены в EXE; основной поиск и база работают без интернета.

## Возможности

- поиск по названиям и ID, каталоги предметов, монстров, рецептов и титулов;
- фильтры, избранное, история и недавно просмотренные записи;
- обычная и мировая добыча, сундуки и подтверждённые награды заданий для титулов и рецептов;
- свойства предметов, дополнения способностей и эффекты комплектов;
- отдельные данные The Original и Iris Kiss Kiss;
- компактный блок лучшей обычной добычи: `название — шанс`;
- предпросмотр последней записи сообщества Iris Online и ручная проверка обновления;
- единичный экземпляр приложения: повторный запуск активирует открытое окно.

Названия и характеристики предметов берутся из общего справочника. Монстры и серверные источники получения учитываются по выбранному серверу; данные одного сервера не подставляются вместо отсутствующих данных другого. Награды за выполнение заданий берутся из общих игровых ресурсов и показываются как общие данные: доступность конкретного задания на выбранном сервере отдельно не утверждается.

Данные встроены в приложение и не синхронизируются автоматически с игровыми серверами Iris Online. После обновлений игры сведения могут временно отличаться от фактического состояния выбранного сервера.

## Запуск

Сборка v2.0.6 создаёт пять вариантов EXE:

| Файл | Система |
| --- | --- |
| `IrisOnlineDB-2.0.6-Windows-x64.exe` | Windows 10/11, Intel/AMD x64 |
| `IrisOnlineDB-2.0.6-Windows-x86.exe` | Windows 10, x86 |
| `IrisOnlineDB-2.0.6-Windows-arm64.exe` | Windows 10/11, ARM64 |
| `IrisOnlineDB-2.0.6-Windows-7-8.1-x64.exe` | Windows 7 SP1, 8, 8.1, Intel/AMD x64 |
| `IrisOnlineDB-2.0.6-Windows-7-8.1-x86.exe` | Windows 7 SP1, 8, 8.1, x86 |

Скачайте подходящий EXE и запустите двойным щелчком. Установщик самой базы не нужен. `SHA256SUMS.txt` содержит контрольные суммы пяти EXE; при публикации меню выпуска подписывает манифест тем же GPG-ключом, что и тег.

Для окна приложения обязателен Microsoft Edge WebView2 Runtime. Если его нет, первый запуск предложит установку встроенным официальным Microsoft Bootstrapper. Нажмите «ОК» и дождитесь завершения; необходим интернет. Скачивание EXE само по себе ничего не устанавливает. После установки Runtime поиск и игровая база работают без сети.

На Windows 7/8/8.1 нужен WebView2 109. Microsoft предусматривает выбор этой версии установщиком Evergreen на старых ОС; компонент больше не получает обновлений безопасности. Если уже установлен Runtime ниже 109, приложение попросит обновить его. Windows 7 требует SP1 и обновления безопасной загрузки DLL (KB2533623 или заменяющего). XP, Vista и Windows RT не входят в цели сборки. Подробности, происхождение исправлений Go и границы проверки: [Windows 7/8/8.1](docs/WINDOWS_LEGACY.md).

Для установки без интернета на Windows 10/11 можно заранее скачать официальный [автономный установщик Microsoft](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution#offline-deployment). Для Windows 7/8/8.1 требуется именно совместимый Runtime 109: текущий автономный установщик новых версий не подходит. Runtime целиком в архив исходников и EXE не включён.

## Хранение и обновление с v1.1

Профиль остаётся в прежнем каталоге `%APPDATA%\IrisOnlineDatabase\UserData\profile.json`; схема профиля v1 сохранена. Поэтому настройки, избранное, история и недавно просмотренные записи из v1.1 переносятся без изменения пути или формата. Кэш WebView2 хранится в `%LOCALAPPDATA%\IrisOnlineDatabase\WebView2`; сборки для Windows 7–8.1 используют соседний каталог `WebView2-Windows7`, чтобы разные версии Runtime не открывали один кэш. Файл профиля общий.

Запись профиля атомарна, с резервной копией. Неизвестные безопасные поля профиля сохраняются для обратной совместимости. Подробнее: [docs/PROFILE_COMPATIBILITY.md](docs/PROFILE_COMPATIBILITY.md).

## Сеть и конфиденциальность

Приложение не содержит телеметрии, аналитики и рекламы. Игровые данные, поисковые запросы, профиль и избранное не отправляются наружу.

Фоновые HTTPS-обращения к GitHub используются для проверки версии и получения новости:

- `github.com` — проверить адрес последнего релиза;
- `api.github.com` — узнать последнюю опубликованную версию и, при необходимости, получить резервную копию `data/latest-vk.json`;
- `raw.githubusercontent.com` — получить подготовленное `data/latest-vk.json` с предпросмотром последней публичной записи ВКонтакте.

ВКонтакте напрямую из приложения не запрашивается. Ссылки на GitHub, ВКонтакте, сайт игры и явно перечисленные сообщества открываются в системном браузере только для разрешённых HTTPS-адресов. При отсутствии сети база продолжает работать, а блоки онлайн-функций показывают последнее корректное состояние или понятную ошибку.

WebView использует внутренний виртуальный адрес `http://wails.localhost`; Wails обрабатывает его внутри процесса. Это не сетевой TCP-сервер, DNS-запрос или доступный пользователю локальный сервер.

На Windows запустите `powershell -ExecutionPolicy Bypass -File .\IrisTools.ps1`. Меню проверяет и устанавливает инструменты, запускает строгую проверку, собирает EXE во внешнюю папку и не создаёт вторую копию исходников. Необязательный `01_TEST.bat` поставляется отдельно от архива исходников: положите его рядом с папкой `iris-online-database` и запустите двойным щелчком. Он только вызывает канонический `IrisTools.ps1 -Action Test`, сохраняет код завершения и оставляет окно открытым.

Архив содержит только папку `iris-online-database`, без `.git`, готовых EXE и временных файлов. Распакуйте её и запустите внешний `00_RELEASE_WINDOWS.bat` → `PREPARE RELEASE`. Если `.git` отсутствует, меню загрузит историю `main` из GitHub и создаст локальный коммит файлов архива, сохранив их содержимое. Нужен интернет. Основа архива записана в `tools/archive_base.txt`; при изменении `main` восстановление устаревших исходников останавливается. Отправка на GitHub выполняется отдельным пунктом меню.

При обновлении существующей рабочей копии сохраняйте её `.git` и предварительно фиксируйте изменения локальным коммитом. Существующая история автоматически не заменяется. Проверка `Test` по-прежнему требует чистое рабочее дерево; архив не содержит готового подтверждения её прохождения.
