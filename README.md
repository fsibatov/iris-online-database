# Iris Online Database 2.0.0

Iris Online Database — неофициальная локальная база предметов, монстров, рецептов, сундуков, комплектов и источников добычи Iris Online.

Версия 2.0 — обычное Windows desktop-приложение. `IrisOnlineDatabase.exe` открывает собственное окно на Wails 2.14.0 и Microsoft WebView2: без адресной строки, внешней вкладки браузера и TCP-порта для интерфейса. HTML/CSS/JavaScript и игровые данные встроены в EXE; основной поиск и база работают без интернета.

## Возможности

- поиск по названиям и ID, каталоги предметов, монстров и рецептов;
- фильтры, избранное, история и недавно просмотренные записи;
- обычная и мировая добыча, квестовые источники, сундуки и рецепты;
- свойства предметов, дополнения способностей и эффекты комплектов;
- отдельные данные The Original и Iris Kiss Kiss;
- компактный блок лучшей обычной добычи: `название — шанс`;
- превью последней записи сообщества Iris Online и ручная проверка обновления;
- единичный экземпляр приложения: повторный запуск активирует открытое окно.

## Запуск

Релиз v2.0.0 содержит три Windows-сборки:

- `IrisOnlineDB-2.0.0-Windows-x64.exe` — основной вариант для большинства ПК с 64-разрядной Windows на Intel/AMD;
- `IrisOnlineDB-2.0.0-Windows-x86.exe` — для 32-разрядной Windows;
- `IrisOnlineDB-2.0.0-Windows-arm64.exe` — для Windows on ARM.

Установка не требуется: скачайте подходящий EXE и запустите его двойным щелчком. `SHA256SUMS.txt` содержит контрольные суммы всех трёх файлов.

Нужен Microsoft Edge WebView2 Runtime. На актуальных Windows он обычно уже установлен. Release содержит небольшой официальный Evergreen Bootstrapper: если Runtime отсутствует или устарел, Wails покажет понятное системное сообщение и предложит установку. Полный Fixed Version Runtime в дистрибутив не включён.

## Хранение и обновление с v1.1

Профиль остаётся в прежнем backend-каталоге `%APPDATA%\IrisOnlineDatabase\UserData\profile.json`; схема профиля v1 сохранена. Поэтому настройки, избранное, история и недавно просмотренные записи текущей v1.1 переносятся без изменения пути или формата. WebView2 использует стабильный отдельный каталог `%LOCALAPPDATA%\IrisOnlineDatabase\WebView2`, а backend остаётся источником истины.

Запись профиля атомарна, с резервной копией. Неизвестные безопасные поля профиля сохраняются для обратной совместимости. Подробнее: [docs/PROFILE_COMPATIBILITY.md](docs/PROFILE_COMPATIBILITY.md).

## Сеть и конфиденциальность

Приложение не содержит телеметрии, аналитики и рекламы. Игровые данные, поисковые запросы, профиль и избранное не отправляются наружу.

Само приложение может выполнять только два фоновых HTTPS-запроса:

- `api.github.com` — узнать последнюю опубликованную версию;
- `raw.githubusercontent.com` — получить подготовленное `data/latest-vk.json` с последним публичным превью VK.

VK напрямую из приложения не запрашивается. Ссылки на GitHub, VK, сайт игры и явно перечисленные сообщества открываются в системном браузере через строгий HTTPS allowlist. При отсутствии сети база продолжает работать, а блоки онлайн-функций показывают последнее корректное состояние или понятную ошибку.

WebView использует внутренний виртуальный origin `http://wails.localhost`; Wails перехватывает его внутри процесса. Это не TCP-listener, DNS-запрос или доступный пользователю localhost-сервер.
