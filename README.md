# Iris Online Database 2.0.4

Iris Online Database — неофициальная локальная база предметов, монстров, титулов, рецептов, сундуков, комплектов и источников добычи Iris Online.

Версия 2.0 — настольное приложение для Windows. `IrisOnlineDatabase.exe` открывает собственное окно на Wails 2.14.0 и Microsoft WebView2: без адресной строки, внешней вкладки браузера и TCP-порта для интерфейса. HTML/CSS/JavaScript и игровые данные встроены в EXE; основной поиск и база работают без интернета.

## Возможности

- поиск по названиям и ID, каталоги предметов, монстров, рецептов и титулов;
- фильтры, избранное, история и недавно просмотренные записи;
- обычная и мировая добыча, сундуки и подтверждённые награды заданий для титулов и рецептов;
- свойства предметов, дополнения способностей и эффекты комплектов;
- отдельные данные The Original и Iris Kiss Kiss;
- компактный блок лучшей обычной добычи: `название — шанс`;
- предпросмотр последней записи сообщества Iris Online и ручная проверка обновления;
- единичный экземпляр приложения: повторный запуск активирует открытое окно.

Названия и характеристики предметов берутся из общего справочника. Монстры и серверные источники получения учитываются по выбранному серверу; данные одного сервера не подставляются вместо отсутствующих данных другого. Награды за выполнение заданий берутся из общих игровых ресурсов и показываются как общие данные: доступность конкретного задания на выбранном сервере отдельно не утверждается.

## Запуск

Релиз v2.0.4 содержит три Windows-сборки:

- `IrisOnlineDB-2.0.4-Windows-x64.exe` — основной вариант для большинства ПК с 64-разрядной Windows на Intel/AMD;
- `IrisOnlineDB-2.0.4-Windows-x86.exe` — для 32-разрядной Windows;
- `IrisOnlineDB-2.0.4-Windows-arm64.exe` — для Windows на ARM.

Установка не требуется: скачайте подходящий EXE и запустите его двойным щелчком. `SHA256SUMS.txt` содержит контрольные суммы всех трёх файлов.

Нужен Microsoft Edge WebView2 Runtime. На актуальных Windows он обычно уже установлен. В релиз включён небольшой официальный Evergreen Bootstrapper: если WebView2 Runtime отсутствует или устарел, Wails покажет понятное системное сообщение и предложит установку. Полный Fixed Version Runtime в дистрибутив не включён.

## Хранение и обновление с v1.1

Профиль остаётся в прежнем каталоге `%APPDATA%\IrisOnlineDatabase\UserData\profile.json`; схема профиля v1 сохранена. Поэтому настройки, избранное, история и недавно просмотренные записи из v1.1 переносятся без изменения пути или формата. WebView2 использует стабильный отдельный каталог `%LOCALAPPDATA%\IrisOnlineDatabase\WebView2`, а файл профиля остаётся источником истины.

Запись профиля атомарна, с резервной копией. Неизвестные безопасные поля профиля сохраняются для обратной совместимости. Подробнее: [docs/PROFILE_COMPATIBILITY.md](docs/PROFILE_COMPATIBILITY.md).

## Сеть и конфиденциальность

Приложение не содержит телеметрии, аналитики и рекламы. Игровые данные, поисковые запросы, профиль и избранное не отправляются наружу.

Само приложение может выполнять только два фоновых HTTPS-запроса:

- `api.github.com` — узнать последнюю опубликованную версию и, при необходимости, получить резервную копию `data/latest-vk.json`;
- `raw.githubusercontent.com` — получить подготовленное `data/latest-vk.json` с предпросмотром последней публичной записи ВКонтакте.

ВКонтакте напрямую из приложения не запрашивается. Ссылки на GitHub, ВКонтакте, сайт игры и явно перечисленные сообщества открываются в системном браузере только для разрешённых HTTPS-адресов. При отсутствии сети база продолжает работать, а блоки онлайн-функций показывают последнее корректное состояние или понятную ошибку.

WebView использует внутренний виртуальный адрес `http://wails.localhost`; Wails обрабатывает его внутри процесса. Это не сетевой TCP-сервер, DNS-запрос или доступный пользователю локальный сервер.

Меню проверяет и устанавливает инструменты, запускает строгую проверку, собирает EXE во внешнюю папку и не создаёт вторую копию исходников.
