# Совместимость пользовательского профиля

Iris Online 1.0 использует существующую схему профиля v1 и сохраняет обратную совместимость с ранее созданными профилями этой схемы.

При загрузке сохраняются поддерживаемые настройки: выбранный сервер, тема, вид, фильтры, избранное, история поиска и недавно просмотренные записи. Поле `recentlyViewed` является необязательным: профиль без него читается нормально.

Безопасные неизвестные поля верхнего уровня сохраняются при обычном round-trip, чтобы обновление приложения не уничтожало совместимые данные будущих или более старых клиентов.

Если основной JSON повреждён или обрезан, приложение проверяет резервную копию. Некорректные отдельные значения нормализуются или пропускаются без очистки всего профиля.
