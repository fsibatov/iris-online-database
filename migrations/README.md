# Совместимость пользовательского профиля

Iris Online Database 1.1.0 продолжает использовать схему профиля v1 и сохраняет совместимость с ранее созданными профилями этой схемы.

При загрузке сохраняются поддерживаемые постоянные настройки: выбранный сервер, тема, вид каталога, избранное, история поиска и недавно просмотренные записи. Фильтры каталогов являются временными и при новом запуске приложения сбрасываются.

Поле `recentlyViewed` необязательно: профиль без него загружается корректно.

Безопасные неизвестные поля верхнего уровня сохраняются при чтении и повторной записи профиля, чтобы обновление приложения не удаляло совместимые данные других поддерживаемых версий.

Если основной JSON-файл повреждён или обрезан, приложение проверяет резервную копию. Отдельные некорректные значения нормализуются или пропускаются без удаления всего профиля.
