# Требования и зависимости Iris Online Database 1.1.0

## Запуск готовой сборки

- Windows 10 или Windows 11: x64, x86 или ARM64.
- Современная версия Microsoft Edge, Google Chrome или Mozilla Firefox.
- Подключение к интернету не требуется для работы локальной базы данных.
- При запуске приложение может выполнить один HTTPS-запрос к публичному GitHub API для проверки новой версии. Если интернет недоступен, эта проверка просто пропускается.
- Внешние страницы открываются только по действию пользователя.

## Сборка из исходного кода

- Go 1.26.5 — требуемая версия для сборки, предназначенной для публикации (`.go-version`).
- Директива языка Go 1.22 (`go.mod`).
- Windows PowerShell 5.1+ или Bash для сценариев сборки.
- Node.js для проверки синтаксиса `web/app.js`.
- Python 3.10+ для автоматических проверок и проверки воспроизводимости Windows-ресурсов.
- GCC или другой совместимый C-компилятор, указанный через `CC`, для `go test -race`.
- Playwright и Chromium — для браузерных интеграционных проверок, если они доступны в среде выполнения.

Сборка другой версией Go разрешается только при явном указании `IRIS_ALLOW_UNSUPPORTED_GO=1`. Такая сборка получает диагностический маркер и не заменяет сборку требуемой версией Go.

## Зависимости приложения

Во время работы приложение использует только стандартную библиотеку Go. Сторонних Go-модулей, JavaScript-фреймворков и CSS-фреймворков нет.

Значок приложения и манифест Windows входят в исходный код. Готовые архитектурные файлы `.syso` позволяют собирать версии x64, x86 и ARM64 без сети и без дополнительных инструментов для Windows-ресурсов.

`tools/generate_windows_resources.py` используется только для детерминированного восстановления и проверки этих ресурсов.

## Кодировки

- исходный код и веб-ресурсы — UTF-8;
- `build.ps1` — UTF-8 with BOM для совместимости с Windows PowerShell 5.1;
- пользовательский интерфейс — русский язык;
- пользовательский профиль — JSON в UTF-8.
