# Требования и зависимости Iris Online 1.0.1

## Запуск готовой сборки

- Windows 10/11: x64, x86 или ARM64.
- Современный Edge, Chrome или Firefox.
- Сетевой доступ не требуется для локальной базы. Интернет нужен только после явного открытия внешней ссылки.

## Сборка исходников

- Целевой toolchain: Go 1.26.5 (`.go-version`).
- Директива языка: Go 1.22 (`go.mod`).
- Windows PowerShell 5.1+ или Bash для build-script.
- Node.js для синтаксической проверки `web/app.js`.
- Python 3.10+ для audit/smoke-тестов и проверки воспроизводимости Windows-ресурсов.
- GCC или другой C-компилятор через `CC` для `go test -race`; `build.ps1` включает `CGO_ENABLED=1` только на время race-проверки и затем возвращает `CGO_ENABLED=0` для Windows EXE.
- Playwright + Chromium для browser UI-smoke, если они доступны в окружении.

Сборка неподдерживаемым Go разрешается только явно через `IRIS_ALLOW_UNSUPPORTED_GO=1`. Она всегда маркируется как diagnostic и не заменяет публикационную сборку требуемым toolchain.

## Зависимости приложения

Runtime использует стандартную библиотеку Go. Сторонних Go-модулей, JavaScript-фреймворков и CSS-фреймворков нет. Иконка и Windows manifest входят в source tree; готовые архитектурные `.syso` позволяют собирать x64/x86/ARM64 без `go-winres`, сети и дополнительных runtime-зависимостей. `tools/generate_windows_resources.py` нужен только для детерминированной регенерации/проверки этих ресурсов.

## Кодировки

- исходники и web-ресурсы: UTF-8;
- `build.ps1`: UTF-8 with BOM для совместимости с Windows PowerShell 5.1;
- пользовательский интерфейс: русский язык;
- профиль: JSON UTF-8.
