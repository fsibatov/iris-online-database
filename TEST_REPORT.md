# Отчёт о проверке Iris Online Database 1.1.0

Дата проверки: 11 августа 2026 года.

## Итог

Версия приложения повышена до **1.1.0**. Проведена полная вычитка пользовательских русских текстов в интерфейсе, сообщениях приложения и сопроводительных файлах. Исправлены орфография, пунктуация, грамматика, стилистика, технические кальки и несогласованность терминов.

Игровые исходные данные не редактировались.

## Основные изменения текста

- унифицированы названия разделов, фильтров, источников получения и элементов навигации;
- технические и неестественные формулировки заменены на понятные русские варианты без изменения смысла;
- пользовательские подписи характеристик приведены к единому стилю, где это не затрагивает игровые названия из базы;
- «Квест» как пользовательская категория источника заменён на «Задание»; внутренние значения источников в данных не менялись;
- пояснение различий между Original и Kiss упрощено;
- пояснение расчёта шанса выпадения переписано без внутренних терминов таблиц;
- сообщения запуска, ошибок и завершения приложения вычитаны и согласованы;
- README, REQUIREMENTS, LICENSE, THIRD_PARTY_NOTICES и файл миграций вычитаны и обновлены для версии 1.1.0.

Игровые строки, которые поступают непосредственно из встроенной базы, намеренно не переписывались.

## Версия и Windows-ресурсы

- интерфейс: `1.1.0`;
- серверный маркер: `1.1.0`;
- сценарии сборки: `1.1.0`;
- Windows-манифест: `1.1.0.0`;
- имена диагностических EXE: `IrisOnlineDB-1.1.0-diagnostic-go1.23.2-Windows-*.exe`.

Требуемая версия Go для публикационной сборки остаётся **Go 1.26.5**, как указано в `.go-version`. В текущей среде доступны диагностические сборки на **Go 1.23.2**; они не должны выдаваться за официальный релиз, собранный требуемой версией Go.

## Проверки

Пройдены:

- `go test ./...`;
- `go test -race -count=1 ./...`;
- `go vet ./...`;
- `node --check web/app.js`;
- 81 из 81 Python unit-тестов;
- API smoke test;
- lifecycle smoke test;
- RSS smoke test;
- проверка архитектуры и диагностических маркеров Windows EXE;
- проверка Windows-ресурсов, манифеста и значков для x64, x86 и ARM64;
- проверка воспроизводимости Windows EXE: две последовательные сборки из одного состояния совпали побайтно.

Полный Playwright UI smoke test в текущей Linux/container-среде не завершился в установленный 180-секундный лимит. После обновления устаревших текстовых ожиданий он не сообщил новой ошибки приложения до истечения лимита, поэтому полный PASS для этого теста не заявляется.
