# Совместимость профиля и миграция

## Профиль приложения

Версии 1.1, 2.0 и 2.1 используют схему профиля `1` и один путь в Windows:

```text
%APPDATA%\IrisOnlineDatabase\UserData\profile.json
```

Сохраняются сервер, тема, вид, избранное, история и недавно просмотренные записи. Поиск и фильтры каталогов намеренно не сохраняются и сбрасываются при новом запуске. Неизвестные корректные поля верхнего уровня JSON сохраняются при чтении и перезаписи.

Размер профиля ограничен. Запись выполняется через временный файл и атомарную замену с резервной копией `%APPDATA%\IrisOnlineDatabase\UserData\Backups\profile.json.bak`. Если основной файл повреждён, загружается резервная копия. Если прочитать оба файла не удалось, запуск останавливается, сохраняя исходные файлы. Профиль по умолчанию создаётся только при отсутствии обоих файлов. Профиль более новой схемы не заменяется старой резервной копией.

Если интерфейс не смог загрузить настройки, сохранение приостанавливается до успешной повторной загрузки. Одновременное сохранение и закрытие приложения не перезаписывают более свежие настройки. Ошибки записи сообщаются без локальных путей пользователя.

## Переход с браузерной версии на WebView2

Версия 1.1 при первом запуске переносит прежний `localStorage` в профиль приложения. v2 использует тот же профиль, поэтому переход на WebView2 не меняет место хранения пользовательских данных. Состояние интерфейса, ожидающее записи, дополнительно хранится в стабильном каталоге `%LOCALAPPDATA%\IrisOnlineDatabase\WebView2` и при следующем запуске используется до успешного сохранения профиля.

Сборки для Windows 7/8/8.1 используют каталог кэша `WebView2-Windows7` рядом с `WebView2`. Сохранённые настройки и избранное берутся из общего `profile.json`. Перед переходом между вариантами завершите сохранение и закройте приложение: ещё не сохранённое состояние из кэша другого Runtime не переносится.

При прямом переходе с версии, в которой ещё не было профиля приложения, сначала один раз запустите последнюю v1.1 и дождитесь главного экрана. Затем штатно закройте её и запускайте v2. Это ограничение безопасности браузера: v2 не читает профили Edge или Chrome напрямую.

Перед обновлением при необходимости можно скопировать папку `%APPDATA%\IrisOnlineDatabase\UserData`; релизный EXE её не удаляет.
