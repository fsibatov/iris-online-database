# Происхождение игровых данных

База 2.1 сохраняет игровые assets коммита `4bb96ba2622f67f846511c5d33afcb7074c60662` без изменения содержимого. Проверка выполнена по предоставленному архиву `Iris Resourses.rar`, а не по действующему серверу игры.

SHA-256 архива: `2df78a9b5d4cf659462c8c08a42b2e0e6c5463209079c046576cf5e3aa3c3565`.

Машиночитаемый реестр [checksums/data_sources.json](../checksums/data_sources.json) содержит пути и SHA-256 файлов источника, исходный коммит, дату сверки, намеренное преобразование таблицы Kiss и точные ID отсутствующих связей. Исходный игровой архив в программу не включён.

| Данные | Источник | Проверка |
|---|---|---|
| Общие предметы, способности, монстры, рецепты | `resource/resource` | Прямые поля и встроенная проекция |
| Русские названия и описания | `Rus/Rus` | Сопоставление ID, названий и примечаний |
| Добыча Kiss | `1/kiss` | Группы, порядок и серверные правила |
| Добыча Original | `1/or` | Группы, порядок и серверные правила |

## Сохранённые неопределённости

| Область | Что требует подтверждения |
|---|---|
| Характеристики предметов | 38 пар расхождений в `assets/item_abilities.json.gz`, поле `conflictsPreserved`: точные ID, поле, встроенное и исходное значения |
| Материалы рецептов | 8 отсутствующих предметов: ID `830050`–`830057` |
| Результаты сундуков | 24 ID без известной записи предмета |
| Локализация | Нет исходных названий для 33 предметов и 62 монстров |
| Эффекты | Не подтверждён смысл кода `320` у двух записей |
| Категория 33 | 576 исключённых исходных строк; добавлять их в обычный каталог без проверки назначения нельзя |

Значения не выбираются автоматически из одного из конфликтующих источников. `raw_projection_audit.py` сравнивает полное множество исключений, включая значения, и отклоняет подмену при неизменном количестве. `data_presentation_audit.py` проверяет согласованность сохранённых значений с текущими assets без внешнего архива.

В Kiss у монстра `10042`, строка `2483` файла `1/kiss/item_dropn.txt`, повторная группа `6000501` с весом 50% следует после той же группы с весом 100%. Встроенная проекция сохраняет первую запись. В базовой модели последовательного выбора вторая недостижима; существующий тест `TestMonster10042PreservesSevenDirectSlots` закрепляет это поведение. Модификаторы действующего сервера этим не подтверждаются.

## Повторная сверка

```powershell
python -B tools/data_presentation_audit.py
python -B tools/raw_projection_audit.py --help
```

Для второй проверки явно передайте пути `--resource` и файлов локализации из распакованного архива. Сверьте SHA-256 источников с реестром до импорта. При обновлении данных изменяйте проекцию, реестр происхождения и согласованные исключения вместе; новый конфликт должен приводить к ошибке проверки.
