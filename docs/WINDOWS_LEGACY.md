# Windows 7, 8 и 8.1

## Запуск

Используйте `IrisOnlineDB-2.0.6-Windows-7-8.1-x64.exe` для Intel/AMD x64 или `IrisOnlineDB-2.0.6-Windows-7-8.1-x86.exe` для x86. Нужны Windows 7 SP1, Windows 8 или Windows 8.1 и Microsoft WebView2 Runtime 109. Для Windows 7 установите обновления, включающие KB2533623 или его замену. Windows XP, Vista, RT и ARM32 не входят в поддерживаемые цели.

Если WebView2 отсутствует, приложение предложит встроенный официальный установщик Microsoft. Установка требует интернета и может требовать разрешения администратора. По документации Microsoft Evergreen выбирает 109 на старых ОС. Если установлен более ранний Runtime, приложение сообщает его версию и просит обновление. При сетевой ошибке установщика повторите установку и запуск; сама база работает без сети после установки Runtime.

Для автономной установки на старую ОС нужен совместимый пакет именно версии 109 из доверенного источника с действительной подписью Microsoft. Текущий Evergreen Standalone для новых ОС и пакет обновления из Microsoft Update Catalog нельзя считать универсальным установщиком 109 с нуля. Runtime не загружается с неофициальных зеркал и не включён в архив проекта.

Microsoft больше не выпускает исправления WebView2 109. Приложение сохраняет CSP, ограничения внешних ссылок и изоляцию встроенного интерфейса, но это не устраняет уязвимости устаревшего Runtime. [Объявление Microsoft и поведение установщика](https://blogs.windows.com/msedgedev/2022/12/09/microsoft-edge-and-webview2-ending-support-for-windows-7-and-windows-8-8-1/).

## Сборка

Все пять EXE собираются на Windows 10/11 через существующий `00_RELEASE_WINDOWS.bat` и канонический `IrisTools.ps1`. Собирать проект на Windows 7/8/8.1 не требуется. Go 1.26.6 и Wails 2.14.0 остаются закреплёнными; официальный Go не переписывается.

`tools/prepare_windows_legacy.py` проверяет версию Go и SHA-256 пяти исходных файлов, применяет локальный дифф во внешнем каталоге BuildTools и сверяет результат. Go `-overlay` подключает эти файлы только к двум сборкам с тегом `windows_legacy`. При несовпадении версии, исходников, диффа или подготовленного overlay сборка останавливается. `.gitattributes` сохраняет LF в диффе независимо от настройки Git `core.autocrlf`.

Изменения стандартной библиотеки:

- `ProcessPrng` заменён на системный криптографический `BCryptGenRandom`, доступный в старых ОС. Ошибки обрабатываются как `NTSTATUS`.
- Восстановлено определение версии ОС и наследование консольных дескрипторов Windows 7 при запуске дочернего процесса.
- Отключено прямое изменение PEB для длинных путей; остаётся штатная обработка путей старой Windows.

Основа диффа — [XTLS/go-win7, закреплённый коммит](https://github.com/XTLS/go-win7/tree/ccc83255f9ad36e06b119066d0b704944afeeb9a). Взята только нужная часть изменений Go 1.26; исправлена обработка результата `BCryptGenRandom`. Патчи `src/os` из этого проекта не включены: проверки границ `os.Root` и удаления файлов остаются из официального Go. Лицензия и все SHA-256 находятся в `tools/compat`.

Сборки имеют одинаковые игровые данные и профиль. Кэш старого Runtime хранится отдельно в `%LOCALAPPDATA%\IrisOnlineDatabase\WebView2-Windows7`. Для CSS `color-mix()` предусмотрены обычные объявления цвета перед расширенными; игровые цвета редкостей сохранены.

## Проверка

Релизный Windows gate запускает тесты обеих архитектур с совместимым Go runtime. Среди проверок — криптографическая случайность, файловые операции с кириллицей и передача вывода дочернего процесса. В EXE дополнительно проверяются полный SHA релизного коммита, SHA патча, теги сборки, системный генератор случайных чисел, PE 6.1, архитектура, ресурсы и защитные флаги. Все пять EXE включаются в SHA256SUMS.

При подготовке исходников выполнены кросс-компиляция и статические проверки. Реальный запуск GUI на Windows 7/8/8.1 в этой среде не выполнен. Перед публикацией проверьте следующие сценарии на каждой заявленной ОС и архитектуре:

1. Первый запуск без Runtime, установка 109 и повторный запуск без интернета.
2. Холодный запуск с установленным Runtime, поиск, смена сервера и открытие карточек.
3. Светлая и тёмная темы, масштаб 100–150%, читаемость редкостей и длинных названий.
4. Сохранение избранного и настроек, закрытие и повторный запуск; второй экземпляр активирует первый.
5. Запуск из пути с пробелами и кириллицей, переход по разрешённой внешней ссылке, сворачивание и восстановление.

Запишите версии ОС, обновлений, WebView2, архитектуру и SHA-256 EXE вместе с результатами. Успех CI на Windows Server 2025 не подтверждает выполнение этих сценариев на старой Windows.
