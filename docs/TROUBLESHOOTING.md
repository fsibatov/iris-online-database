# Устранение проблем

## fatal: not a git repository

В распакованном архиве нет `.git`. Запустите `00_RELEASE_WINDOWS.bat` → `PREPARE RELEASE`: меню восстановит историю из канонического `main` и зафиксирует исходники локально. Файлы проекта не перезаписываются. При сетевой ошибке повторите запуск; неполная `.git` не остаётся в проекте. Если `main` изменился после подготовки архива, требуется актуальный архив. Повреждённая существующая `.git` автоматически не удаляется.

## WebView2 не установлен

Разрешите приложению запустить встроенный Evergreen Bootstrapper или установите Runtime с официальной страницы Microsoft WebView2. После установки перезапустите EXE. На Windows 7/8/8.1 используйте EXE с суффиксом `Windows-7-8.1-x64` или `Windows-7-8.1-x86` и Runtime 109. Новые версии Runtime на этих ОС не работают; подробности установки: [WINDOWS_LEGACY.md](WINDOWS_LEGACY.md).

## Старый Windows сообщает об отсутствующей функции или DLL

Проверьте имя EXE: обычные сборки требуют Windows 10/11. На Windows 7 нужен SP1 и системные обновления, включая KB2533623 или заменяющее. Не скачивайте отдельные DLL с посторонних сайтов. Сообщение о неподготовленной сборке означает, что EXE собран без проверенного overlay; пересоберите через `00_RELEASE_WINDOWS`.

## Приложение уже запущено

Второй запуск должен активировать существующее окно. Проверьте панель задач и Alt+Tab. Если после аварийного завершения процесса нет, новый запуск сразу создаёт окно: single-instance lock принадлежит процессу и не использует stale lock file или порт.

## Новости или проверка версии недоступны

Основная база остаётся полностью рабочей без интернета. Для проверки версии разрешите исходящий HTTPS/443 к `github.com` и `api.github.com`; для обновления превью новости также нужен `raw.githubusercontent.com`. Приложение напрямую к ВКонтакте не подключается.

Проверка версии различает основные причины сбоя: отсутствие сети, тайм-аут, временную недоступность GitHub, ограничение частоты запросов и некорректный ответ. Если GitHub сообщает `Retry-After` или исчерпанный rate limit, приложение не повторяет сетевой запрос до окончания указанного интервала. После временной ошибки сохраняется последний успешно подтверждённый статус версии и последнее корректное превью новости.

Если сообщение повторяется после указанного времени, проверьте системные дату и время, DNS, VPN/прокси и правила firewall/антивируса для HTTPS. Не отключайте защиту целиком: достаточно разрешить перечисленные домены.

## Профиль не загрузился

Закройте приложение и сохраните копию `%APPDATA%\IrisOnlineDatabase\UserData`. Проверьте `Backups\profile.json.bak`. Не редактируйте profile во время работы приложения.

## Диагностика сборки

Запустите `IrisTools.ps1 -Action Check`, затем `-Action Test`. Gate не считает network timeout успешной security-проверкой. Generated files и audit environments находятся вне source; если Git status изменился, сначала осознанно разберите изменения, не используйте `git reset --hard` или `git clean -fdx`.

`Check` и `Install` автоматически показывают стандартный Windows UAC prompt. Строка `PowerShell` должна содержать `Administrator / OK`. Если UAC отменён, повторите команду и подтвердите запрос; вручную запускать весь release gate от администратора не нужно.

Если `govulncheck` выдаёт `NETWORK/INFRASTRUCTURE SKIP`, разрешите исходящий HTTPS/443 к `vuln.go.dev` и `storage.googleapis.com` в firewall/proxy, затем повторите `-Action Test`. Это не означает, что в коде найдена уязвимость, но и не подтверждает её отсутствие: до успешного запроса RELEASE-gate остаётся закрытым.

Если winget только что установил Git или Node.js, launcher обновляет `PATH` текущего процесса и проверяет executable повторно. Строки Ruff, Bandit, pip, pip-audit, Playwright и PyYAML относятся к изолированному окружению `%LOCALAPPDATA%\IrisOnlineDatabase\BuildTools\python-audit`, а не к глобальному Python.

При `Workflow validation: FAIL [WF001]` строка выше указывает файл workflow, задание, шаг, строку и столбец PowerShell. Ошибка `MissingArgument` в шаге CodeQL исправлена: список тегов Go передаётся одним аргументом в кавычках. Валидатор использует Windows PowerShell 5.1; отсутствие парсера или тайм-аут остаются ошибкой проверки.

Каждый запуск pip-audit получает новый каталог `iris-pip-audit-*` в `%TEMP%`. После завершения сканирования он удаляется, включая случай ошибки сканера. Старый кэш внутри Python-окружения больше не используется; предупреждение о правах на его файлы не требует запуска всего выпуска от администратора.
